# Elm VSCode

My personal language extension for Elm in VSCode

![](/logo.jpg)

## Features

- Format On Save
- Syntax Highlighting
- Compiler Diagnostics
- Code Completion

## Requirements

| binary     | version   | releases                                    |
| ---------- | --------- | ------------------------------------------- |
| elm        | >= 0.19.1 | https://github.com/elm/compiler/releases    |
| elm-format | >= 0.8.8  | https://github.com/avh4/elm-format/releases |

| platform |
| -------- |
| windows  |
| macos    |
| linux    |
